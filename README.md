- [Описание ограничений исходников](1DevKit_v19.14.41_Nexus-GitHub/README.md)

**SHA-256 оригинального архива:** `5932ac3c5698eb181ff9635af82f8a51a585bd585732165c31060de2c139b21d`.

Файл имеет расширение RAR, но фактически является ZIP-контейнером. Внутри 175 файлов: 169 GI, 3 DAT, 1 SCR, 1 TXT и 1 DLL. Оригинальный архив сохранён неизменённым.

169 файлов DAT/GI восстановлены в редактируемый JSON. `recover.py` повторяет извлечение, `build.py` собирает игровой ZIP. По результатам автоматической проверки все 175 файлов внутри восстановленного ZIP побайтно совпадают с оригиналом. Шесть файлов не восстановлены как редактируемые исходники: DLL, SCR, три GI и ModuleInfo.txt (его исходный текст есть в установочном архиве).
