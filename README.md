# DevKit — Space Rangers HD

Мод DevKit для «Космических рейнджеров HD».

## DevKit v19.14.41

- [Установочный архив DevKit_v19.14.41.rar](1DevKit_v19.14.41_Nexus-GitHub/install/DevKit_v19.14.41.rar)
- [Отдельная папка версии v19.14.41 для Nexus/GitHub](1DevKit_v19.14.41_Nexus-GitHub)
- [Исходники и инструменты восстановления](1DevKit_v19.14.41_Nexus-GitHub/scripts)
- [Описание ограничений исходников](1DevKit_v19.14.41_Nexus-GitHub/README.md)

**SHA-256 оригинального архива:** `5932ac3c5698eb181ff9635af82f8a51a585bd585732165c31060de2c139b21d`.

Файл имеет расширение RAR, но фактически является ZIP-контейнером. Внутри 175 файлов: 169 GI, 3 DAT, 1 SCR, 1 TXT и 1 DLL. Оригинальный архив сохранён неизменённым.

Скрипт `recover.py` извлекает поддерживаемые DAT и GI в редактируемые JSON (каталог `source/`); `build.py` позволяет восстановить игровой ZIP. Авторские исходники DLL и SCR отсутствуют в присланном архиве, поэтому не все ресурсы могут быть восстановлены как редактируемый текст.
