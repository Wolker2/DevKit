# DevKit v19.14.41 — новая версия, отдельно от v18

Это **новая папка**, содержащая оригинальный полный архив `install/DevKit_v19.14.41.rar` (на деле ZIP-контейнер с расширением RAR). SHA-256 `5932ac3c5698eb181ff9635af82f8a51a585bd585732165c31060de2c139b21d`.

`python scripts/recover.py` извлекает редактируемые исходники DAT и совместимых GI в `source/` и создаёт SHA-256 манифест. `python scripts/build.py` собирает полный игровой архив, применяя отредактированные исходники. В проект включены кодеки из старых Nexus-пакетов, без обращения к Windows, DevKit и папке установленной игры.

**Ограничение:** этот присланный архив содержит только игровые бинарные файлы, без авторского RSON и исходника DLL. Три GI-изображения также не декодируются общим кодеком. Они, как и SCR, DLL, остаются доступными в оригинальном ZIP и участвуют в сборке без изменения. **Это не полностью восстановленные исходники** — нельзя выдавать за эквивалент исходного комплекта v18. При этом не повреждён ни один файл владельца, не переименована старая версия и не заявлен неподтверждённый релиз.
